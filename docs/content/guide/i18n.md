---
title: Multiple languages
---

The engine routes by locale itself - this is not a plugin bolted on afterwards. One locale is the
*root*: its pages are served without a prefix, and every other locale gets one.

```fsharp
Site.create "Docs"
|> Site.locales
    [
        Locale.root "en" |> Locale.withLabel "English"
        Locale.other "fr" |> Locale.withLabel "Français"
        Locale.other "ar" |> Locale.withLabel "العربية" |> Locale.rightToLeft
    ]
```

## Where translations live

A directory named after a locale claims the pages inside it, and drops out of the route:

```text
content/
├── guide/
│   └── setup.md        ->  /guide/setup/
└── fr/
    └── guide/
        └── setup.md    ->  /fr/guide/setup/
```

Both pages share a route key - `guide/setup` - and that is how the engine knows they are the same
page in two languages. The language picker and the fallback below both work from that key.

If you declare a single locale you pay nothing for any of this: `fr/` is then just a directory.

## Untranslated pages

Translation is never finished, so a half-translated site still has to be usable. When a page is
missing from a locale, Nacara generates it from the default locale's content and marks it as
untranslated, and the theme says so at the top of the page:

:::note Not translated yet
This page has not been translated into Français yet - you are reading the 'en' version.
:::

The alternative - a 404, or a menu entry that quietly disappears - is worse for a reader in either
language. Set `Site.fallBackToDefaultLocale false` if you would rather ship nothing than ship the
original.

## The language picker

`NavbarLocalePicker` lists the locales and links to *the translation of the page you are reading*,
not to the home page. A locale that has no translation of that page still appears, marked as
such.

```fsharp
NavbarEnd = [ NavbarLocalePicker ]
```

## Direction

`Locale.rightToLeft` sets `dir="rtl"` on the document for that locale. The theme's layout uses
logical properties where it matters, so a right-to-left locale reads correctly without a stylesheet
of its own.
